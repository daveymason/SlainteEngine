Squad C • Agents 06–11 • Clinician-in-the-Loop Bedside & Revenue Copilots

Save Clinician Hours. Block Prescribing Errors. Capture Unbilled DRG Revenue.

Six embedded clinical and revenue agents grounded strictly in HL7 FHIR R4 evidence and deterministic Python FastMCP safety tools.

Inside Agents 06 through 11

  • Agent 06: SlainteEngine-Ingest

    Harmonizes native HL7v2 pipe-hat streams (ADT^A01, ORU^R01, RDE^O11), batch CSVs, clinical PDFs, and handwritten triage images into deduplicated FHIR R4 bundles.

  • Agent 07: SlainteScribe-Brief

    Produces concise 4-bullet clinical handover summaries citing exact [ResourceType/id] tags and logging every prompt/response hash to ai_exchange.

  • Agent 08: SlainteRx-Guard (3-Tier)

    Screens Tier 1 Drug-Allergy cross-reactivity, Tier 2 ISMP High-Alert Drug-Drug Interactions, and Tier 3 Patient Lab eGFR & Potassium renal contraindications.

  • Agent 09: SlainteDx-Triage

    Computes deterministic Manchester Triage Category 1–5 priority and 24-hour Royal College of Physicians NEWS2 deterioration trajectories.

  • Agent 10: SlainteScribe-Voice

    Ambient clinical voice scribe converting live consultation speech into SOAP DocumentReferences, SNOMED/ICD-10 Conditions, and Rx-Guard pre-screened orders.

  • Agent 11: SlainteRev-Coding

    Cross-checks objective biomarkers (eGFR < 60, HbA1c ≥ 48, Troponin > 50, Lactate ≥ 2.0) against coded Conditions to capture missed HIPE / ICD-10-AM comorbidities.
