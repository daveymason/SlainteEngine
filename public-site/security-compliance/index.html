Frequently Asked CISO & DPO Questions

Can Slainte-Engine run with zero internet access so no PHI ever leaves the hospital VLAN?

Yes. In Sovereign Air-Gap mode, Slainte-Engine pairs with an on-premise Ollama GPU server (or runs purely deterministic Agents 01–06, 08, 09, and 11 without any LLM at all), ensuring zero external network egress.

How is audit log tampering prevented even if an application session is compromised?

Six compiled database triggers (BEFORE UPDATE and BEFORE DELETE on audit_log, ai_exchange, and break_glass_grants) abort any mutation attempt at the storage engine layer, backed by HMAC-signed JSON audit snapshots and real-time SIEM forwarding.

How do clinicians handle acute emergencies when RBAC restricts prescribing?

Clinicians invoke the audited Break-the-Glass workflow under GDPR Art. 9(2)(c) vital-interests provisions, recording a mandatory clinical justification that unlocks a 60-minute emergency grant while immediately dispatching a signed CRITICAL alert to the CISO SIEM.
